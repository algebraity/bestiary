Bestiary for Windows
====================

Run install.bat to copy Bestiary and its required DLLs into:

  %LOCALAPPDATA%\Bestiary

You can choose another folder when the installer asks.

The DLL files must stay in the same folder as bestiary.exe, bestiary-cli.exe,
and repl.exe. If you copy only an exe file somewhere else, Windows may report
that DLLs are missing.

For a portable install, you can also run bestiary.exe directly from this folder
without running install.bat.
